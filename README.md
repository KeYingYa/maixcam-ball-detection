# MaixCAM2 钢球检测（OpenCV）

运行在 **MaixCAM2** 上的钢球视觉检测程序：开启补光 LED，利用钢球表面反光形成的亮点，用 OpenCV 定位球心，并通过串口把坐标发给下位机（STM32）。

## 检测原理

1. **补光**：点亮 LED（GPIO B25），钢球表面形成高亮反光点
2. **预处理**：灰度化 → 中值滤波 → 固定阈值 / 自适应阈值（均值、高斯两种可选）
3. **去噪**：形态学开运算 + 闭运算
4. **筛选**：轮廓面积过滤 + 区域平均亮度过滤
5. **定位**：椭圆拟合 / 图像矩求球心
6. **稳定**：连续 N 帧确认（抗单帧误检），并统计丢失帧

## 串口协议

| 项 | 值 |
|---|---|
| 设备 | `/dev/ttyS4`（UART4），115200-8-N-1 |
| 引脚 | A21 = UART4_TX，A22 = UART4_RX |
| 帧头 | `0xAA`，其后为坐标等字段（见 `main.py` 中的 `SerialComm`） |

## 交互（触摸屏）

- 右上角 LED 按钮：开关补光
- 左半画面：切换「调参 / 全屏」
- 右半画面：重置计数
- 底部参数按钮：选中并调节阈值、面积、形态学核大小等，参数持久化到 JSON

## 文件

| 文件 | 说明 |
|---|---|
| `main.py` | 主程序：检测 + 调参 UI + 串口输出 |
| `stream_only.py` | 纯推流精简版（WebRTC / HTTP 预览） |
| `app.yaml` | Maix 应用描述（id / 版本 / 入口） |
| `old/main.py` | 旧版实现（保留对照） |

## 运行

把整个目录作为应用放到 MaixCAM2 的 app 目录，或在开发环境用 `maix` SDK 运行 `main.py`。
`app.yaml` 中 `version: 7.0.1`、`author: lzr`。

> 依赖：MaixPy（`maix` 模块）+ OpenCV（`cv2`）+ NumPy。
